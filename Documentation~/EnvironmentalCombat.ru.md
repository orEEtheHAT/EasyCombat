# Урон от столкновений и эффекты областей

**Удар.** Назначь `Health` и `ImpactDamageDefinition` компоненту `ImpactDurability`. Для автоматического измерения добавь на Rigidbody `RigidbodyImpactSource` и укажи получателя. SO выбирает нормальную скорость сближения, импульс столкновения или высоту падения. Можно отфильтровать слой поверхности и коллайдер тела. Порог сравнивается с величиной в единицах выбранного режима; горизонтальная поверхность для приземления определяется относительно гравитации.

Только превышение безопасного порога передаётся в кривую урона. Результат ограничивается MaximumDamage и идёт в обычный `Health.ApplyDamage` с типом из SO. Защитные слои, резисты, журнал и события смерти продолжают работать. RepeatDelay ограничивает частоту для одного получателя и сбрасывается при смене жизни.

**Внешний источник.** Для собственного датчика выбери `ImpactMeasure.External` и передай измерение в `TryImpact(measure, magnitude, point, normal, center, out result)`. Его единицы и порог определяет вызывающий код. Возврат true означает, что запрос передан, а не что цель потеряла HP. При необходимости игровая реализация `ImpactDurability.IsProtected(center)` может отклонить удар до расчёта; базовая реализация не добавляет правил игры.

**Замедление без урона.** У разового выстрела используй StatusOnly и OnHitStatuses: после попадания действует длительность статуса. Если замедление нужно только внутри сектора, используй `MovementField` с `CombatAreaTrigger`. У AreaTriggerDefinition выбери Area.Shape=Cone, Duration=0 для непрерывного действия, оставь Enter/Stay/Exit Attack пустыми. Источник может включать и выключать поле через Fire()/Cease(). Для эффекта от обычного trigger Collider используй MovementSurface.

На цели нужны `MovementInfluences` и адаптер её способа движения. Для геометрической выборки CombatAreaTrigger нужен боевой получатель с коллайдером. При выходе на следующей выборке или остановке источника снимается только его вклад. Несколько полей используют самый сильный множитель. Временные контактные эффекты не сохраняются — игра заново запускает нужные поля после загрузки.

**Движение.** Для NavMeshAgent задай базовую скорость через `NavMeshSpeedAdapter.BaseSpeed`; при смене походки под эффектом пересчитывается действующий предел. Для FPS есть опциональная интеграция EasyMovement: импортируй её sample и выбери **EasyCombat → Integrations → Create EasyMovement Combat Player**. Множитель применяется один раз после выбора походки. Если нужны также обычные временные статусы, назначь MovementSpeedStat тот же ключ, что указан в статусе.
