# EasyMovement FPS adapter

Install EasyMovement with ECM2 first. Import this sample, then use **EasyCombat → Delivery → Create EasyMovement Combat Player**. The local copy preserves the original FPS prefab's input, gait and camera references. The adapter scales the selected gait and analog input floor once and supports spatial fields plus the optional status movement key. Do not combine it with an adapter that already scales the same underlying speeds. See Documentation~/DeliveryEnvironment.ru.md.
